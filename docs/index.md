# Cairn

Cairn is an amateur radio digital protocol. This site collects its
documentation and its architecture decision records (ADRs).

- **[Operator guide](operator-guide.md)** — install, set up, first contact and
  unattended operation with the reference modem.
- **[Writing ADRs](writing-adrs.md)** — how to propose and change decisions.
- **Handbook** — the decisions currently in force. Start here if you are
  implementing Cairn.
- **Records** — every ADR, including superseded and rejected ones.
- **Changelog** — what each commit changed in the decision record.
